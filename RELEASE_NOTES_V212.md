# v2.12.0-epidemics

Final submission snapshot for Epidemics.

## Main changes
- Restores continuous COVID-19 infection-equivalent curves with burden and population percentage for every wave.
- Restores continuous COVID-19 mortality curves with excess and official deaths for every wave.
- Rebuilds the 1918 visual account as separate infection-equivalent and mortality figures.
- Retains the documented U.S. Army spring morbidity and mortality sentinels before Spain's May 1918 wave.
- Uses overlapping smooth display components that preserve archived wave integrals without truncating epidemic tails.
- Keeps identifiability, simulation, timing-sensitivity, and portability qualifications explicit.
